## 🚀 How to Deploy to GitHub Pages (Free Live Website)

1. Create a new repository on GitHub (e.g. `atk-fans-efootball-league`).
2. Push all files from this folder (`index.html` and the `assets/` folder) to your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: ATK Fans eFootball League points table"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/atk-fans-efootball-league.git
   git push -u origin main
   ```
3. In your GitHub repository:
   * Go to **Settings** > **Pages** (under Code and automation).
   * Under **Branch**, select `main` and folder `/ (root)`.
   * Click **Save**.
4. In under 1 minute, your live website will be accessible at:
   `https://<YOUR_USERNAME>.github.io/atk-fans-efootball-league/`
